# 诸葛亮八阵图 · 推演沙盘

使用 Three.js 展示九宫八阵与军队，以队为单位推演战斗。士兵、枪盾、弓弩、骑兵、旗帜、四轮车与战鼓均由程序建模，场景包含江岸地形、群山、阴影、箭雨、扬尘与阵亡士兵。

当前版本：**1.1.0**。

## 功能

- 九宫八阵、四正四奇、中军预备队与中宫通道中的游骑，可点选高亮、近观和查看队伍状态。
- 八阵图、一字横阵、方阵、圆阵、鹤翼阵、锋矢阵，均使用同样的 8420 人及兵种构成。
- 正面强攻、铁骑冲阵、侧翼迂回、背后奇袭、四面合围、攻坚敌阵六种敌情。
- 兵力、士气、疲劳、侧背攻击、骑兵冲击、枪阵反挫、轮换、奇兵侧击、溃散与追击。
- 开战、暂停、重新布阵、四档倍速、战报定位、镜头跟随、士气环与战果弹窗。
- 36 格对比矩阵，每格取种子 11、18、25 的三场平均；内置 108 场数据，也可在浏览器通过 Web Worker 重算。
- 桌面与手机布局，镜头根据面板位置调整取景。

## 本地运行

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

运行引擎回归检查：

```bash
npm test
```

更新内置对比数据（需要等待 108 场推演完成）：

```bash
npm run simulate
```

单场诊断：`node scripts/trace.mjs bazhen cavalry 11`。参数依次为阵型 ID、敌情 ID、种子。

## 代码位置

- `src/sim/`：不依赖 DOM 或 Three.js 的纯 JS 推演引擎、阵型、敌情、随机数与内置结果。
- `src/render/`：地形、模型、实例化士兵及特效。
- `src/main.js`：界面、镜头、战报、结果与 Worker 调度。
- `src/lore.js`：阵法讲解。
- `scripts/`：批量推演、诊断与回归检查。

## 推演边界

这是用于观察阵型与号令差异的简化战术模型，不是历史战役还原。界面中的阵法配置与兵力是本项目的建模设定。所有阵型共用兵种参数，结果由站位、号令、敌情和随机种子决定；八阵并非在每种敌情下都获胜。

模拟假设号令畅通，未建模补给、天气、地形对移动和战斗的影响；地形目前用于视觉呈现。每格三次推演只能表示当前参数下的小样本表现，金框表示胜负优先、交换比辅助的综合得分最高。

固定种子用于同一运行环境内复现；Node 内置结果与浏览器重算可能因浮点运算差异而出现不同战果，浏览器重算只更新当前页面，刷新后恢复内置数据。
